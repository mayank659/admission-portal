# College Admission Portal

A web-based College Admission Portal developed using **PHP, MySQL, HTML, CSS, and JavaScript** to simplify student admission record management.

## Features

- **Student Management:** Store and manage student admission details.
- **Search and Filter:** Find student records using different search criteria.
- **Academic Session Management:** Organize student records by academic session and course.
- **Admission Document Management:** Add, update, activate, and deactivate required admission documents.
- **Document Tracking:** Track admission document status for individual students.
- **Data Export:** Export student records to CSV for use in spreadsheet applications.
- **Print Support:** Print student records in a structured format.
- **Responsive Interface:** User-friendly interface for managing admission records.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Development Environment:** XAMPP

## Installation and Setup

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone or download this repository.
3. Place the project folder inside the XAMPP `htdocs` directory.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Open phpMyAdmin in your browser.
6. Create the required MySQL database and import the project database SQL file, if provided.
7. Configure the database connection in `connect.php`.
8. Open the project in your browser:

   `http://localhost/your-project-folder/`

## Project Purpose

The main purpose of this project is to make college admission record management easier by providing a centralized system for storing, searching, and managing student information and admission document requirements.
